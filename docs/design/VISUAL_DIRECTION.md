# Visual direction

Z Cloud is a professional creative studio. The content is the hero; the interface is the instrument.

The visual language is obsidian graphite with a restrained sandstone accent. Use narrow, aligned controls, fine dividers, editorial headings and generous photographic surfaces. Avoid generic KPI dashboards, decorative gradients, glass effects and large empty cards.

The initial working screen is the Media Library: workspace navigation, a media-first center, and context-sensitive inspector. The collection cover introduces a story while the grid remains the main working area. Metadata sits below images with quiet contrast. Selection and primary actions use the warm accent.

The sidebar contains workspace destinations, collections and quick access. Its lower region holds settings and truthful local storage information. The status bar reports local readiness; it must never pretend cloud sync is active.

The inspector provides Details, Memories, AI and Publish. Metadata, tags, collection membership, memories and captions are editable. The AI tab links to explicit text generation in the AI workspace, which reports server configuration and real errors. Remote publishing remains visibly unconfigured.

Support desktop, laptop, tablet and mobile without horizontal page scrolling. On small viewports the sidebar is a dismissible overlay and the inspector becomes an overlay or full-width sheet. Keep media browsing and editing available.

The live shell is English/LTR by default, with a persistent RTL layout option. A complete Persian translation is future work; do not claim RTL layout alone is localization.
